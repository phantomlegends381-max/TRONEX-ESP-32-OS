# TRONEX-ESP-32-OS
Its an OS based on breadboard ESP 32 and PI 5 in which you go inside PI 5 for searching on the internet, ai command prompts, And for Esp 32 side is for file utilities, linux commands, computer settings, file explorer customized, git bash scripting. pI 5 basically acts as an chrome .

## Virtual desktop features

Open the desktop from **Launch OS**. The file explorer can create and edit text documents, add local files, download a selected file, and export the current folder as a ZIP. Files are stored in the current browser's local storage; download copies you want to keep elsewhere.

The browser panel runs Google searches and opens websites in a new tab when embedding is blocked. TRONEX Assistant uses Google's Gemini API. Paste your own Gemini API key into the assistant to chat. The key stays in that browser session and is sent directly to Google. Because this site is public and static, use a restricted key and usage limits; production apps should keep API keys on a server.
